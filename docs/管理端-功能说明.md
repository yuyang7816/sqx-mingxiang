# 管理端功能说明

管理端是给**平台工作人员**用的网站，在电脑浏览器里打开。C 端用户日常听课、助眠、开通会员**不使用**这个网站。

它用来：

- 管课程、章节、探索分类、音效
- 管注册用户、会员、订单、财务
- 发站内消息、改帮助文章和协议
- 填写微信、支付、短信、图片存储这些外面服务的账号

程序里的名称是「省钱兄冥想助眠系统」。工作人员登录后，**左侧是菜单**。能看到哪些菜单，由账号权限决定。没有权限的菜单不会出现。

下面的页面名称以当前后台侧栏与开源 SQL 菜单为准。如果你后来在「菜单管理」里改过名字，以你屏幕上看到的为准。

怎么启动见 [管理端运行教程](管理端-运行教程.md)。

---

## 登录

登录页要填：

1. 账号
2. 密码
3. 图片验证码（看不清就点图片换一张）

验证码由服务端生成。服务端没启动时，图片是裂的，登录也会失败。

开源包 SQL 已带演示管理员：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |

登录成功后默认进入数据中心。

---

## 数据中心

登录后的首页。数字来自自己的数据库，不连外面的公司。

上方常见卡片：

- 总用户数
- 今日新增、本月新增、本年新增
- 总收入、今日收入、本月收入、本年收入

下方可用日期筛选，查看「总用户统计」等图表 / 明细（以页面实际页签为准）。

这些数字在有真实用户和支付之后才会增长。刚导入 SQL 时，可能是 0 或只有演示数据，这是正常的。

---

## 用户中心

### 用户列表

查看在用户端注册的账号。可按用户名称、手机号、邀请码、是否会员筛选。

列表上常见列：

- 用户名称、头像、性别、手机号
- 当前余额、是否会员、会员到期时间
- 渠道来源、自己的邀请码、邀请人邀请码
- 支付宝账号、微信收款码
- 状态开关（启用 / 禁用）
- 注册时间

每行常见按钮（以权限为准）：

| 按钮 | 做什么 |
|---|---|
| 用户详情 | 进入详情页，看资料、会员、钱包等 |
| 赠送会员 | 不经过支付，直接给该用户开通一段时间会员 |
| 取消会员 | 去掉会员身份 |
| 删除 | 删除该用户（危险操作，请谨慎） |
| 状态开关 | 禁用后该用户可能无法正常登录使用 |

改金额、改状态等敏感操作以页面实际按钮与权限为准。改完保存后立刻生效。

### 注销信息

用户在用户端「设置中心 → 注销账户」提交申请后，会出现在这里。工作人员可查看并处理注销。

## 课程管理

这是后台最核心的业务页。用户端首页推荐、探索列表、课程详情都来自这里。

### 课程列表

可按课程类型、课程名称、课程标题、导师、状态查询。可添加、修改、删除。

添加 / 修改一门课程时，常见字段：

- 课程类型（对应「类型配置」里的冥想类型，用户端首页横向分类用它）
- 探索一级 / 二级分类（对应「类型配置 → 探索分类」，用户端「探索」页用它）
- 课程名称、课程标题、课程简介、备注
- 导师名称、导师头衔、导师简介、导师头像
- 封面、背景图片
- 标签（对应「类型配置 → 标签列表」，详情页上的小标签）
- 课程状态：正常 / 下架（下架后用户端不再展示）

### 章节

在课程列表里进入「章节」，可为这门课添加多节音频：

- 章节名称、封面、序号
- 章节音频（上传或填写链接）
- 章节时长
- 是否会员专享：标成专享后，未开通会员的用户在用户端会看到锁，无法完整播放
- 状态：正常 / 下架

改完点确认保存。用户端需要重新打开课程详情才会看到新章节。

**注意：** 部分上传按钮可能仍写着线上地址。本地上传失败时，把上传地址改成本机服务端，见运行教程。

## 类型配置

三个页签：

### 冥想类型列表

首页横向分类的名称和描述，例如「冥想入门」「放松舒缓」。用户端首页每个类型下面会横滑展示该类型的课程。

可添加、修改、删除。删掉类型前，先确认没有课程还在用它。

### 标签列表

课程详情页上的小标签，例如「助眠」「减压」。添加课程时可勾选。

### 探索分类配置

用户端「探索」顶部的分类，例如「冥想」「睡眠」「声音」。

- 可设置是否启用
- 每条一级分类可以再点「二级分类」，例如「全部 / 助眠 / 减压」
- 未启用的分类不会出现在用户端探索页

## 音乐场景配置

维护助眠、专注、小憩、呼吸页面用到的背景音效：

- 名称
- 封面图片
- 音频文件
- 排序

用户端在「夜间睡眠 / 专注时钟」等页面点「音乐」时，列表来自这里。改完保存后，用户端下次进入再拉一次即可。

---

## 订单中心

查看用户开通会员等产生的支付订单。可按用户名称、订单号、状态、充值方式筛选。

订单状态常见为：

- 待支付
- 支付成功
- 支付失败

支付方式可能显示：App 微信、微信公众号、微信小程序、支付宝等。

点用户名可跳到该用户详情。真正退款按钮以页面权限为准；没配支付密钥时，这里可能一直没有成功单，这是正常的。

---

## 财务中心

四个页签：

### 提现管理

用户在用户端「我的钱包」提交提现后，出现在这里。可按状态、手机号、支付宝名称、提现方式、时间筛选。

常见信息：手机号、支付宝账号 / 名称、微信收款码、金额、状态。

审核通过后，**系统一般不会自动打款到微信或支付宝**。请工作人员按用户填写的收款信息，到对应平台人工转账，再在后台把状态改掉（以页面按钮为准）。

### 提现统计 / 支付统计 / 支付记录

查看汇总数字和流水，便于对账。数字来自自己的数据库。

## 会员配置

用户端「会员中心」里可购买的套餐：

- 会员名称（例如季卡、年卡）
- 月数
- 会员价格

添加或修改并保存后，用户端会员中心下次打开会显示新套餐。价格是给支付用的；没配支付时用户仍能看到套餐，只是付不了款。

---

## 会员特权

展示在用户端会员中心上半部分的特权图标：

- 特权名称
- 图片
- 排序

这是展示用文案 / 图标，不自动开通微信会员卡。付费章节能不能听，看的是用户是否会员，以及章节有没有标「会员专享」。

## 首页装修

### 首页轮播图

用户端首页顶部大图。可添加图片、名称，并用开关控制显示 / 隐藏。

隐藏后用户端下次打开首页不再展示该张。点击轮播后跳到哪里，以添加时填的跳转配置为准（有的只展示图）。

### 首页分类

部分版本还有「首页分类」页签，用于首页其它展示位。以你屏幕上实际页签为准。

---

## 帮助中心

两个页签：

- **分类管理**：帮助文章的分类
- **文章管理**：标题、所属分类、正文

用户端关于我们、部分说明文案也可能走协议配置。改完保存后，用户端再打开对应页面才会更新。

---

## 消息中心

两个页签：

### 用户消息

给用户发**站内消息**（不是手机短信）。用户在用户端「我的 → 消息提醒」里能看到。可刷新列表查看已发送内容。

### 用户反馈

查看用户从 App 里提交的反馈（若已启用该入口）。

---

## 系统配置

这是最重要的配置中心。外面服务的账号大多填在这里。改完要点保存。用户端下次请求才会用新的密钥或文案。

常见页签：

| 页签 | 用来做什么 |
|---|---|
| 全局系统配置 | 网站域名、基础项。上传文件拼出来的 https 地址常依赖这里的域名 |
| 微信配置 | 小程序 / 公众号 AppId、Secret，以及微信支付相关参数 |
| 支付宝配置 | 支付宝商户参数 |
| 短信配置 | 用哪家通道发验证码、模板、是否模拟发送 |
| 服务费配置 | 提现手续费、最低最高提现金额等 |
| APP 消息推送配置 | App 推送通道参数 |
| 文件上传配置 | 走本地目录还是云存储（如阿里云 OSS）的开关和密钥 |
| 开关配置 | 功能总开关（是 / 否） |
| 协议配置 | 用户服务协议、隐私政策、VIP 权益条款、关于我们、注销协议等富文本 |

没填微信 / 支付 / 短信时：

- 后台其它菜单仍可用
- 用户端能浏览课程、做倒计时练习
- 验证码登录可能发不出短信（或只能用模拟码）
- 开通会员可能拉不起支付
- 微信登录会提示未开通

## 系统管理

### 管理员列表

谁能登录这个后台。可添加工作人员账号、改密码、分配角色。

演示账号 `admin` 不要随便删。

### 角色管理

角色 = 一组菜单权限。例如「只让客服看订单和用户，不让改系统配置」。

### 菜单管理

左侧菜单的名称、图标、排序、对应页面地址。一般不要随意删除，否则侧栏会缺页。

---

## 和用户端怎么配合

管理端不自己保存用户的听课结果。它把操作发给服务端，服务端再写入数据库。所以：

1. 服务端没启动时，验证码出不来，登录会失败。
2. 在这里改完课程、会员套餐、音效、轮播并保存后，用户端下次打开才会看到。
3. 外面的密钥只配在「系统配置」里。用户端没有地方填写微信支付商户号。
4. 给用户赠送会员后，用户端「我的」应显示已开通及到期时间（需用户重新进入页面）。

用户端每个按钮对应什么，见 [用户端功能说明](用户端-功能说明.md)。服务端会连哪些外面的公司，见 [服务端功能说明](服务端-功能说明.md)。
