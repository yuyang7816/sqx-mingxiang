# 服务端运行教程

这份教程面向**不会写代码**的人。请按顺序做。做完一步，先看到文中写的成功标志，再做下一步。不要跳步。

## 服务端是什么

三个端里，**服务端要第一个启动**。

可以把它理解成「总台」：

- 管理端（电脑后台）和用户端（手机 / 网页）自己不会改数据库。
- 它们把「登录、查课程、播放、开通会员、提现」这些请求发给服务端。
- 服务端检查是否允许，把结果存进数据库。需要发短信、收微信付款、存图片时，再去问外面的公司。

代码在文件夹：`mingxiang-server`  
数据库脚本在：`mingxiang-server/db/mingxiang.sql`

服务端没启动时，管理端和用户端也许能打开界面，但登录会失败，课程列表也可能是空的。

---

## 开始之前要准备什么

在自己的电脑上安装下面三个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 打开终端，输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 8.0（5.7 一般也可） | 能连上本机 MySQL，端口一般是 **3306** |

### 怎样打开终端

- **Windows**：按键盘 `Win + R`，输入 `powershell`，回车。或者开始菜单搜索「PowerShell」。
- **macOS**：打开「终端」（Terminal）。
- **Linux**：打开 Terminal。

### Java 怎么装

**不要装成 11、17 或 21。** 本项目只能用 Java 8。装错版本时，先卸掉，再装 1.8。

下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

装完后**必须关掉原来的终端，再打开一个新的**，然后输入：

```bash
java -version
```

看到类似 `1.8.0_xxx` 就成功了。如果提示「不是内部或外部命令」，说明安装时没有勾选添加到 PATH，需要重装并勾选。

### Maven 怎么装

下载：https://maven.apache.org/download.cgi  
选 `apache-maven-3.x.x-bin.zip`，解压后把里面的 `bin` 文件夹加到系统 PATH。

加完 PATH 后同样要**关掉终端再开一次**，再输入：

```bash
mvn -v
```

能看到 `Apache Maven 3` 和 `Java version: 1.8` 就成功了。

### MySQL 怎么装

安装过程中会让你给 `root` 设一个密码，还会让你确认端口（一般是 3306）。**把密码和端口记在纸上或备忘录里**，后面第 4 步要用。

也可以用图形软件 Navicat、MySQL Workbench、phpMyAdmin 来连数据库，不会命令行也没关系。

### Redis 要不要装

本项目默认 **不强制** 启动 Redis（配置里 `sqx.redis.open` 是 `false`）。  
第一次把项目跑起来，可以先不装 Redis。以后如果你打开了 Redis 缓存，再自行安装，并把 `application.yml` 里的 `spring.redis` 改成你的环境。

## 第 1 步：新建空数据库

SQL 文件会建表并写入演示数据，但**不会自己创建**名叫 `mingxiang` 的库。要先建库，再导入。

### 方法 A：用命令行

1. 打开终端，登录 MySQL（把「你的密码」换成安装时设的 root 密码）：

```bash
mysql -uroot -p你的密码
```

2. 执行：

```sql
CREATE DATABASE IF NOT EXISTS mingxiang DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

3. 再执行：

```sql
SHOW DATABASES;
```

列表里有 `mingxiang` 就成功了。输入 `exit` 退出。

如果提示 `Access denied`，是密码错了，用安装 MySQL 时设的那个密码重来。

### 方法 B：用 Navicat（推荐给不习惯命令行的人）

1. 打开 Navicat，新建连接到本机 MySQL（主机 `127.0.0.1`，端口 `3306`，用户 `root`，密码是你设的那个）。
2. 右键连接 →「新建数据库」。
3. 数据库名填 `mingxiang`，字符集选 `utf8mb4`，排序规则选 `utf8mb4_general_ci`。
4. 点确定。左侧出现 `mingxiang` 就成功了。

---

## 第 2 步：导入项目里的数据库文件

文件位置（相对整个项目文件夹）：

`mingxiang-server/db/mingxiang.sql`

这份脚本里包含：

- 全部业务表（课程、章节、用户、会员、订单、音效场景、系统配置等）
- 管理端账号 `admin` / `123456`
- 后台菜单与角色（数据中心、课程管理、订单中心、会员配置、系统配置等）
- 演示用的课程、轮播等内容（以脚本实际数据为准）

**导入会覆盖同名的表**，所以请导入到上一步新建的空库 `mingxiang`，不要导入到别的业务库。

### macOS / Linux 示例

把密码、端口改成你的 MySQL。先用终端 `cd` 到整个项目文件夹（里面能看到 `mingxiang-server`、`mingxiang-admin`、`mingxiang-uniapp` 这三个文件夹），再执行：

```bash
mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 mingxiang < mingxiang-server/db/mingxiang.sql
```

### Windows PowerShell 示例

先把终端切到整个项目文件夹，再执行（MySQL 安装路径若不同，改第一行）：

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p你的密码 -P3306 --default-character-set=utf8mb4 mingxiang -e "source $($PWD.Path -replace '\\','/')/mingxiang-server/db/mingxiang.sql"
```

执行结束时没有 `ERROR`，再执行下面这句，能看到很多表名（含 `sys_user`、`sys_menu`、`course_info`、`tb_user` 等），就说明导入成功：

```bash
mysql -uroot -p你的密码 -P3306 -e "USE mingxiang; SHOW TABLES;"
```

### 用 Navicat 导入（推荐）

1. 双击打开 `mingxiang` 库。
2. 菜单选「运行 SQL 文件」或右键库名 →「运行 SQL 文件」。
3. 选中项目里的 `mingxiang-server/db/mingxiang.sql`。
4. 编码选 **UTF-8**。
5. 点开始。进度走完、没有红色错误，再刷新，能看到很多表，就成功了。

---

## 第 3 步：确认管理员账号

导入成功后，管理端默认账号已经在库里：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |

登录管理端时还要输入一张**图片验证码**（由服务端生成）。服务端没启动时，验证码图片是裂的。

如果以后忘记密码，初学者最省事的办法是：**重新导入一次 SQL**（会覆盖数据）。不要自己去改密码哈希。

---

## 第 4 步：让程序连接你自己的 MySQL

服务端要知道「数据库在哪、账号密码是什么」。这些写在配置文件里。

1. 用记事本、VS Code 或 IDEA 打开：

`mingxiang-server/src/main/resources/application.yml`

仓库默认是：

```yaml
spring:
  profiles:
    active: prod
```

本仓库目前用 `application-prod.yml` 作为本地 / 生产共用配置，**一般不用改成 dev**。保持 `prod` 即可。

2. 打开：

`mingxiang-server/src/main/resources/application-prod.yml`

找到类似下面的几行，把数据库地址、账号密码改成你的：

```yaml
url: jdbc:mysql://127.0.0.1:3306/mingxiang?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=CTT
username: 用户名
password: 密码
```

说明：

- 把 `用户名`、`密码` 换成你的 MySQL 账号密码（一般是 `root` 和你安装时设的密码）。
- 端口不是 3306 时，把 URL 里的 `3306` 改成你的端口。
- **库名必须保持 `mingxiang`**（与第 1 步新建的库一致）。
- 改完后保存文件。

仓库里的配置可能写着别的主机或占位符「用户名 / 密码」，本地联调时务必改成你自己电脑上的 MySQL。

## 第 5 步：启动服务端

有两种办法，任选一种。窗口要一直开着，关掉就等于服务停了。

### 方法 A：用命令行（Maven）

1. 打开终端，进入 `mingxiang-server` 文件夹。  
   例如整个项目在桌面时：

```bash
cd mingxiang-server
```

Windows PowerShell 示例：

```powershell
cd "C:\Users\你的用户名\Desktop\开源-三端\冥想三端开源\mingxiang-server"
```

2. 执行：

```bash
mvn clean package -DskipTests
mvn spring-boot:run
```

或者打包后直接运行 jar：

```bash
mvn clean package -DskipTests
java -jar target/mingxiang-3.0.0.jar --spring.profiles.active=prod
```

第一次会下载很多依赖，可能要 **10 到 30 分钟**，请耐心等，不要关窗口。

看到类似下面的字才算启动成功：

```text
冥想项目启动成功
```

同时会有 Spring Boot 常见的 `Started SqxApplication`。

### 方法 B：用 IDEA（图形界面）

1. 安装 IntelliJ IDEA（社区版即可）。
2. 用 IDEA 打开 `mingxiang-server`（选**有根 `pom.xml` 的那一层**，不要只打开里面的某个子文件夹）。
3. 等右下角 Maven 导入结束（进度条走完）。
4. 左下角或设置里，Project SDK 选 **1.8**。
5. 菜单「File」→「Settings」→「Plugins」，搜索并安装 **Lombok**，然后勾选「Enable annotation processing」。
6. 打开 `src/main/java/com/sqx/SqxApplication.java`。
7. 确认 Active profiles 为 `prod`（右上角运行配置里可以填 `prod`）。
8. 点左侧绿色三角运行。
9. 下方控制台同样要出现「冥想项目启动成功」。

不要关闭这个窗口 / 不要点红色方块停止。关闭后服务端就停了，管理端验证码会裂，用户端登录会失败。

## 怎样算成功

用 Chrome 或 Edge 打开：

http://127.0.0.1:9120/sqx_fast/swagger-ui.html

能看到 Swagger 接口文档页面，就说明服务端已经在听请求。

如果这个页面打不开，只要启动日志里有「冥想项目启动成功」，并且接下来管理端能打开登录页上的验证码图片，也算服务端已经就绪。

服务端默认：

| 项目 | 值 |
|---|---|
| 端口 | `9120` |
| 接口前缀 | `/sqx_fast` |
| 接口文档 | `http://127.0.0.1:9120/sqx_fast/swagger-ui.html` |

接下来请按 [管理端运行教程](管理端-运行教程.md) 启动后台，再按 [用户端运行教程](用户端-运行教程.md) 启动手机端。

短信、微信、支付宝、图片存储这些密钥需要自己到对应官网申请，再填进管理端「系统配置」各页签。没填密钥时，浏览课程、登录页界面、练习倒计时仍可看；真正发短信、收款、微信登录会失败。用途说明见 [服务端功能说明](服务端-功能说明.md)。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
Java 没装好，或装成了更高版本。安装 Temurin 8，关掉终端再打开，重新执行 `java -version`。

**`mvn` 不是内部或外部命令**  
Maven 的 `bin` 没有加到 PATH。加完后必须关掉终端再开一次。

**`Access denied for user 'root'`**  
MySQL 密码和 yml 里的 `password` 不一致。把 yml 里的密码改成你安装时设的密码。

**`Communications link failure`**  
本机 MySQL 没有开，或 URL 里的主机 / 端口不对。先确认 MySQL 服务已启动，核对 URL 后重启服务端。

**`Unknown database 'mingxiang'`**  
第 1 步的建库没有成功。回到命令行或 Navicat 把建库再做一次。

**导入 SQL 时中文变问号**  
命令里要带 `--default-character-set=utf8mb4`。用 Navicat 时，运行 SQL 文件的编码选 UTF-8。

**启动报 Redis 相关错误**  
当前默认关闭 Redis。若你打开了 `sqx.redis.open`，请先启动 Redis，并把密码、端口与 `application.yml` 里的 `spring.redis` 保持一致。

**`Port 9120 was already in use`**  
9120 端口已经被占用。把之前开着的服务端窗口关掉，或在任务管理器里结束对应的 Java 进程，然后再启动。

**管理端验证码图片是裂的**  
服务端没启动，或管理端连的不是 `http://127.0.0.1:9120/sqx_fast`。

**用户端收不到短信验证码**  
若管理端 / 服务端开启了短信模拟，请按配置使用固定验证码（常见为 `123456`）。正式发短信需要配置真实短信通道。

**用户端支付 / 微信登录提示失败**  
管理端「系统配置」里的支付、微信参数未填写，或服务端访问不了对应厂商接口。浏览课程、看学习记录等基础功能仍可本地联调。

**控制台一直停在下载依赖**  
第一次启动需要从网上拉 jar 包。检查网络，或配置 Maven 使用阿里云镜像后再试。不要中途关掉窗口。
