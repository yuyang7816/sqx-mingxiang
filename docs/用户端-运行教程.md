# 用户端运行教程

这份教程面向**不会写代码**的人。请按顺序做。

用户端是给普通用户用的**手机应用 / 电脑网页**。应用名称是「码兄冥想」。底部一直有三个按钮：**首页、探索、我的**。代码在文件夹：`mingxiang-uniapp`。

推荐用 **HBuilderX** 打开这个文件夹来运行。

**必须先把服务端跑起来。** 请先完整做完 [服务端运行教程](服务端-运行教程.md)。首页课程、探索、登录的数据都来自服务端。服务端没启动时，页面也许能打开，但登录会失败，课程列表也可能是空的。

开源 SQL 通常带有演示课程。C 端用户可自行注册，没有单独的固定演示账号也没关系。

---

## 开始之前要准备什么

### 1. 安装 HBuilderX

官网：https://www.dcloud.io/hbuilderx.html

下载「**正式版**」（不要下 Alpha 除非你知道自己在做什么）。解压或安装后打开软件，窗口标题是 HBuilderX，就说明安装成功。

### 2. 可选：Node.js

如果运行后按钮、输入框样式花屏或控制台报 uView 相关错误，需要安装 Node.js（建议 18 或更高）：https://nodejs.org/

装完后在 `mingxiang-uniapp` 目录执行一次：

```bash
npm install
```

这会安装 `uview-plus` 等界面组件。只看页面、样式正常时，可以先不做这一步。

### 3. 可选：微信开发者工具

只在电脑浏览器里看，**不需要**微信开发者工具。

要在微信小程序里看，再安装：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

---

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开：

`mingxiang-uniapp/common/config.js`

仓库默认可能是线上地址：

```javascript
const ROOTPATH = "https://mingxiang.xianmaxiong.com/sqx_fast";
```

### 在自己电脑上联调（推荐）

改成你的本机服务端，保存文件：

```javascript
const ROOTPATH = "http://127.0.0.1:9120/sqx_fast";
const ROOTPATH3 = "ws://127.0.0.1:9120/sqx_fast/";
```

说明：

- 端口必须与服务端一致，默认 **9120**
- 路径必须带 **`/sqx_fast`**
- 改完后要**重新运行**一次用户端，修改才会生效

手机真机调试时，不要用 `127.0.0.1`（那是手机自己）。改成电脑的局域网 IP，例如 `http://192.168.0.109:9120/sqx_fast`，并保证手机和电脑连同一个 Wi-Fi。电脑防火墙要放行 9120 端口。

### 只想先看界面、暂时不跑本机服务端

可以保持线上地址：

```javascript
const ROOTPATH = "https://mingxiang.xianmaxiong.com/sqx_fast";
```

注意：这时你改的页面代码，请求的仍是**线上数据**，不是你本机数据库。管理端在本机改的课程，用户端看不到。

---

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」（有的版本叫「打开文件夹」）。
3. 选中 **`mingxiang-uniapp` 这个文件夹**。
   - 不要选它的上一级（那一层还有 `mingxiang-server` 和 `mingxiang-admin`）。
   - 不要只选里面的某个页面。
4. 左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`、`static` 等，就打开对了。

---

## 第 3 步：在电脑浏览器里运行（最简单）

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. 地址以控制台里打印的为准（常见是类似 `http://localhost:端口`）。
4. 打开后底部应能看到三个入口：**首页、探索、我的**。

**HBuilderX 不要关。** 关掉后页面会打不开。

如果按钮、输入框样式花屏或控制台报 uView 错误，在 `mingxiang-uniapp` 目录执行：

```bash
npm install
```

然后再菜单里重新「运行到浏览器」一次。

---

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开「服务端口」。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里小程序 `appid` 若仍是原项目号码，你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时：

- 把 `appid` 改成你自己的小程序 AppID，或
- 继续只用浏览器运行

微信开发者工具里如果提示域名不合法，本地调试请勾选：

**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

## 怎样算成功

按下表逐项看。都满足就说明用户端连上服务端了。

1. 能打开首页，看到问候语（如「下午好」）、轮播图、四个圆形入口（夜间睡眠 / 专注时钟 / 日间小憩 / 正念呼吸）和课程推荐。
2. 底部三个按钮能点：**首页、探索、我的**。当前页的图标是蓝色的。
3. 点「探索」，顶部有「冥想 / 睡眠 / 声音」等分类，下面是课程卡片。
4. 点「我的」，未登录时顶部是「登录」；能看到累计登录、累计冥想、今日数据、其他服务列表。
5. 按键盘 `F12`，点「网络」或 Network，再刷新。列表里的请求地址应是你在第 1 步配置的地址。若仍出现 `mingxiang.xianmaxiong.com`，说明第 1 步没有保存，或改完后没有重新运行。

### 本地如何注册和登录

1. 打开「我的」，点顶部「登录」。
2. **先勾选**底部「同意《用户服务协议》及《隐私权政策》」。不勾选通常无法登录。
3. **密码登录**：输入手机号 + 密码，点「登录」。
4. **验证码登录**：切换到「验证码登录」，获取验证码。
   - 若服务端 / 管理端开启了短信模拟，按后台说明填写固定验证码（常见为 `123456`）。
   - 未开模拟则需要管理端配好真实短信通道，手机才能收到验证码。
5. 没有账号：点「立即注册」。填写用户名、手机号、验证码、密码；邀请码可空着。同样要勾选协议，再点「立即注册」。
6. 忘记密码：点「忘记密码」，走验证码重置。

登录成功后会回到「我的」，能看到昵称、是否会员、累计数据。

### 建议验收路径（给不懂代码的人）

按这个顺序点一遍：

1. **首页**：点一门推荐课程，进入详情，能看到封面、标签、导师、章节列表。免费章节能点播放；会员专享章节未登录或未开通会员时会看到锁。
2. **夜间睡眠**：回首页，点「夜间睡眠」。能拨时长，点「开始睡眠」后出现倒计时。底部有「闹钟」「音乐」。点「结束睡眠」可停。
3. **专注时钟 / 日间小憩**：同样能选分钟数、开始 / 结束。
4. **正念呼吸**：能选时长，开始后出现吸气 / 呼气引导。可点「模式」切换呼吸模式，可点「音乐」。
5. **探索**：切换「冥想 / 睡眠 / 声音」，列表会变化。右上角放大镜可搜索。
6. **我的**：登录后看累计登录、今日数据。点「今日数据」能切换「今日 / 全部」，能看一周里每一天。
7. **会员中心**：点「开通会员」或「查看权益」，能看到特权图标和套餐。真正付款需要管理端配好支付密钥。
8. **邀请好友**：能看到自己的邀请码，可复制。
9. **设置中心**：能看到修改密码、注销、协议、退出登录。

每个页面更细的说明见 [用户端功能说明](用户端-功能说明.md)。

## 常见问题

**运行菜单是灰的，或提示没有浏览器**  
先安装 Chrome 或 Edge，再重启 HBuilderX。项目必须用「打开目录」打开 `mingxiang-uniapp`，不能打开整个三端大文件夹。

**一直停在「正在编译」，或浏览器是白屏**  
等控制台不再滚动。若出现红色报错，把第一行红色文字记下来。常见原因：打开的文件夹不是 `mingxiang-uniapp`、编译器还没下完、缺少 `npm install`。

**首页能开，但登录失败 / 接口报错 / 课程是空的**  
服务端没有启动，或 `mingxiang-uniapp/common/config.js` 仍是错误地址 / 错误端口。先看服务端窗口是否还有「冥想项目启动成功」，再把第 1 步改成 **9120** 和 `/sqx_fast`，保存后重新运行用户端。

**收不到短信验证码**  
本地若开启模拟短信，请填固定验证码。正式环境需要管理端「系统配置 → 短信配置」填真实通道。

**微信支付、支付宝点了没反应**  
需要自己的支付商户参数。开源代码一般只能看到支付按钮，不能真的完成收款，除非你在管理端配齐密钥。

**课程或音频播不出来**  
确认服务端已启动，章节音频地址用浏览器单独打开能响。未登录或未开通会员时，会员专享章节会被锁住。电脑浏览器播放音频需要允许自动播放时，按浏览器提示允许。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。

**真机预览接口失败**  
不要用 `127.0.0.1`。改成电脑局域网 IP，并检查电脑防火墙是否放行 9120 端口。手机和电脑必须同一 Wi-Fi。

**底部没有「首页 / 探索 / 我的」**  
打开的不是 `mingxiang-uniapp`，或编译失败。重新用「打开目录」打开正确文件夹再运行。
