# 用户端功能说明

用户端是普通用户在**手机或电脑网页**里打开的应用。应用名称是「码兄冥想」。底部一直有三个按钮：**首页、探索、我的**。

这份说明按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信这些外面的服务。

怎么启动见 [用户端运行教程](用户端-运行教程.md)。

---

## 这个端是给谁用的

- **普通用户**：浏览冥想课程、播放章节、夜间睡眠 / 专注 / 小憩 / 呼吸练习、开通会员、看练习数据、邀请好友、申请提现。
- **平台工作人员不使用这个应用。** 改课程、改系统配置、审提现、管全平台订单，在电脑上的管理端做。

---

## 登录、注册、找回密码

从「我的」点顶部「登录」进入。登录前需要勾选《用户服务协议》和《隐私权政策》，不勾选通常无法继续。

### 密码登录

输入手机号 + 密码，点「登录」。账号来自注册，或管理端里已有的用户。

### 验证码登录

切换到「验证码登录」，输入手机号，点获取验证码，填短信验证码后登录。

- 管理端若开启短信模拟：按后台说明填固定码（常见为 `123456`），不会真的发短信。
- 未开模拟：必须在管理端配好短信通道，手机才能收到。没配时按钮点了也收不到。

### 注册

点「立即注册」，填写：

- 用户名
- 手机号
- 短信验证码
- 设置密码
- 邀请码（可以空着；填了会绑到邀请人）

同样要勾选协议，再点「立即注册」。

### 找回密码

点「忘记密码」，用手机号 + 验证码设置新密码。

### 微信登录

在微信小程序 / 微信内更常见。需要管理端已配置微信参数。没配时会提示暂未开通。授权后可能还要绑定手机号。

## 首页

打开应用就是首页。从上到下常见内容：

1. **问候语**：例如「hi，小暴燥」「下午好」。已登录会显示你的昵称。
2. **分享图标**（已登录且非微信小程序时）：可弹出分享文案。
3. **轮播图**：图片来自管理端「首页装修」。可能可以点进去跳转（以后台配置为准）。
4. **四个圆形入口**：
   - 夜间睡眠
   - 专注时钟
   - 日间小憩
   - 正念呼吸
5. **课程推荐**：按类型分块（例如「冥想入门」「放松舒缓」）。每块可横滑，显示封面、课程名、副标题。点「更多」进入该类型列表。点某门课进入课程详情。
6. **迷你播放器**：正在播放课程或音乐时，底部附近会出现小播放条，可暂停 / 继续，点进去进完整播放页。
7. 下拉可刷新。

首页数据来自服务端。服务端没启动或接口地址配错时，轮播和课程可能是空的，四个入口仍可点进去看界面。

## 四种练习入口

四个入口都不强制先登录就能看界面。开始练习后，时长会记入「今日睡眠 / 今日专注」等统计（需能连上服务端；未登录时部分统计可能记在本地或记不上，以实际提示为准）。

### 夜间睡眠

1. 用滚轮选择预计睡眠时长，页面显示「预计睡眠：x 小时 x 分钟」。
2. 点「开始睡眠」，进入倒计时。
3. 底部可点「闹钟」（回到时间选择相关能力）、「音乐」（打开助眠音乐列表，音乐来自管理端「音乐场景配置」）。
4. 点「结束睡眠」停止。
5. 倒计时结束可能弹出提醒（App 上更完整；浏览器能力有限）。

### 专注时钟

1. 选择要专注的分钟数。
2. 点「开始专注」，进入倒计时。
3. 同样可配音乐。点「结束专注」停止。

### 日间小憩

和专注类似，面向白天短休息。选分钟数 →「开始小憩」→ 倒计时 →「结束小憩」。可配音乐。

### 正念呼吸

1. 选择时长。
2. 点开始后，中间出现吸气 / 呼气（或屏息）的动画和秒数，并显示总剩余时间。
3. 点「模式」可切换呼吸模式（不同吸呼节奏）。
4. 点「音乐」可配背景音。
5. 再点按钮可「结束呼吸」。

这些练习页的音乐列表来自服务端音效配置。没配音效时，倒计时仍可用，只是没有曲子。

## 课程详情与播放

从首页推荐或探索点进一门课。

详情页常见内容：

- 顶部大背景图
- 标签（如助眠、减压）
- 课程名称、副标题、简介
- 导师头像、头衔、名称；可点开看导师简介
- 心形：喜欢 / 取消喜欢（一般需登录）
- **章节列表**：序号、章节名、时长。  
  - 可播放的显示播放图标。  
  - **会员专享**且当前账号不是会员时显示锁。点锁会提示登录或开通会员。
- 相关推荐：横滑其它课程
- 底部可能有播放 / 开通会员按钮

点某一节进入**完整播放页**：大封面、播放 / 暂停、上一首下一首、进度条。付费章节未解锁时无法完整听。

播放时，其它页面可能出现迷你播放条，可继续听。课程播放和背景音乐一般不同时播，播课程会停掉音乐（以实际交互为准）。

## 探索

底部第二个按钮。

1. 顶部大标题「探索」。
2. 一级分类横滑：如 **冥想、睡眠、声音**（来自管理端「探索分类配置」，未启用的不会出现）。
3. 其下可能还有二级分类：全部、助眠、减压等。
4. 右上角放大镜：进入搜索页，按关键词找课。
5. 下面是两列课程卡片：封面、名称、副标题。点进去就是课程详情。
6. 滑到底会加载更多；没有数据时显示空状态。

未登录一般也可浏览。播放会员专享内容时会引导登录或开通会员。

分类和课程都来自服务端。服务端没启动时，这里常常是空的。

## 我的

底部第三个按钮。

### 未登录

顶部显示默认头像和「登录」。点它进入登录页。下方统计多为 0。会员条显示「加入会员…」和「开通会员」（点了通常会先让登录）。

### 已登录后上半部分

点头像区域进入**个人信息**：

- 头像（可上传；上传走文件接口，没配存储时可能失败）
- 用户名、年龄、手机号（手机号一般不能改）
- 性别

统计：

- **累计登录**：多少天
- **累计冥想**：总时长
- **我的喜欢**：点进去是喜欢过的课程列表，可再进详情

会员条：

- 未开通：文案「加入会员 权益升级…」，按钮「开通会员」
- 已开通：显示到期时间，按钮「查看权益」

### 今日数据

三张卡片：今日冥想、今日睡眠、今日专注（带时长）。点整行「今日数据」进入统计页：

- **今日**：当月累计次数、一周日期、某一天的三项时长
- **全部**：累计登录天数、累计冥想 / 睡眠 / 专注

数据来自你在课程播放和四种练习里产生的学习记录。刚注册时都是 0，这是正常的。

### 其他服务

| 入口 | 做什么 |
|---|---|
| 消息提醒 | 在线客服入口 + 系统消息列表（管理端「消息中心」发的站内信）。有未读时显示红点数字 |
| 最近播放 | 听过的课程列表 |
| 邀请好友 | 我的邀请码、复制、立即邀请、已邀请人数和累计收益、邀请到的好友 |
| 我的团队 | 仅当账号有推广比例（`zhiRate > 0`）时显示。看下级和收益 |
| 我的钱包 | 可提金额、申请提现、绑定支付宝 / 微信收款码、钱包明细、提现记录 |
| 关于我们 | 后台协议 / 文章配置的「关于我们」文案 |
| 设置中心 | 见下一节 |

## 会员中心

从「我的」会员条进入。

- 显示是否已开通、到期时间
- 特权图标（来自管理端「会员特权」）
- 套餐列表：名称、月数、价格（来自管理端「会员配置」）
- 选套餐后走支付：微信或支付宝（取决于当前是 H5 还是小程序，以及后台是否配齐密钥）

支付成功后，会员身份由服务端根据支付回调开通。没配密钥时，往往只能看到套餐，付不了款。工作人员也可在管理端给用户「赠送会员」。

开通后，课程里标成会员专享的章节可以解锁播放。

## 钱包与提现

「我的钱包」页：

1. 看到可提金额。
2. 输入提现金额。
3. 选择提现方式（如支付宝；页面可能还支持微信收款码）。
4. 点「立即提现」提交申请。
5. 可进入：提现账号（填支付宝账号和姓名）、微信收款码（上传二维码图）、钱包明细、提现记录。

页面上可能显示最低提现金额、手续费说明（来自管理端「服务费配置」）。

**重要：** 提交成功只表示后台多了一条待审核记录。管理端财务中心审核通过后，**系统不会自动把钱打到你的支付宝或微信**，需要工作人员人工转账。

---

## 邀请好友与团队

- 每人有一个邀请码，可点击复制。
- 「立即邀请」会弹出分享相关提示（小程序可用右上角转发；H5 多为复制文案）。
- 新用户注册时填写你的邀请码，会显示在你的邀请列表里。
- 「我的邀请战绩」：已邀请人数、累计收益。
- 有推广权限的账号多一个「我的团队」，可看下级和收益明细。

邀请关系记在自己的数据库。加微信好友、发朋友圈仍是用户自己的动作，系统不会自动发消息给微信。

## 设置中心

| 项目 | 做什么 |
|---|---|
| 修改密码 | 输入旧密码和新密码 |
| 注销账户 | 阅读注销协议后提交注销申请，由管理端处理 |
| 用户服务 | 用户服务协议正文 |
| VIP 权益条款 | 会员相关条款 |
| 关于我们 | 关于我们 |
| 隐私政策 | 隐私政策 |
| 注销协议 | 注销说明 |
| 退出登录 | 确认后清空本地登录态，回到未登录 |

协议正文来自管理端「系统配置 → 协议配置」。改后台文案后，用户端再打开这些页才会更新。

## 这个端真正会连到外面的服务

短信、微信、支付宝、图片存储的密钥填在**管理端「系统配置」**（由服务端去调用）。只改用户端页面上的字，不会变成已经开通。

| 你在页面上做的事 | 要申请的服务 | 官网 | 填在哪里 | 没填密钥时 |
|---|---|---|---|---|
| 注册、验证码登录、找回密码 | 短信服务商（短信宝 / 阿里云 / 腾讯云等） | https://cloud.tencent.com/product/sms 、 https://www.aliyun.com/product/sms | 管理端「短信配置」 | 验证码发不出去；模拟模式下可填固定验证码 |
| 微信登录 | 微信公众平台 | https://mp.weixin.qq.com/ | 管理端「微信配置」 | 提示微信登录暂未开通 |
| 开通会员微信支付 | 微信支付商户平台 | https://pay.weixin.qq.com/ | 管理端「微信配置」 | 无法拉起微信支付 |
| 开通会员支付宝 | 支付宝开放平台 | https://open.alipay.com/ | 管理端「支付宝配置」 | 无法拉起支付宝 |
| 头像、收款码等上传 | 阿里云 OSS（或本地磁盘） | https://www.aliyun.com/product/oss | 管理端「文件上传配置」 | 上传失败或只能走本地路径 |

### 不用申请外面的 Key 就能用的

服务端和数据库就绪即可：

- 浏览库里已经有的课程、章节、轮播、探索分类
- 播放免费章节（音频文件本身要能打开）
- 夜间睡眠 / 专注 / 小憩 / 呼吸的倒计时界面
- 喜欢、最近播放、今日数据（数据在自己库里）
- 看会员套餐和特权说明（真正付款仍需支付配置）
- 邀请码展示、协议文案

### 看起来像外面的服务，但不会自动连出去完成

- **提现**：只保存申请，等管理端审核后人工打款
- **分享 / 邀请链接**：生成分享内容，加好友仍是用户自己的动作
- **在线客服**：按后台配置跳转或展示二维码 / 链接，不是系统自动外呼

## 和另外两端怎么配合

1. 用户端不直接改数据库。点按钮 → 请求发到服务端 → 服务端记账或去问微信 / 短信。
2. 管理端改完课程、音效、会员套餐、轮播并保存后，用户端要重新打开或下拉刷新才会看到。
3. 三个窗口（服务端、管理端、用户端）都要一直开着。先开服务端，再开另外两个。
4. `mingxiang-uniapp/common/config.js` 必须指向你正在跑的那台服务端。指向线上时，本机管理端改的数据用户端看不到。
