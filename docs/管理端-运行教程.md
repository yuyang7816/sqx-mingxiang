# 管理端运行教程

这份教程面向**不会写代码**的人。请按顺序做。

管理端是**电脑浏览器里的后台网站**，不是手机应用。工作人员用它管课程、会员、订单和系统配置。程序名称是「省钱兄冥想助眠系统」。代码在文件夹：`mingxiang-admin`。

**必须先把服务端跑起来。** 请先完整做完 [服务端运行教程](服务端-运行教程.md)。服务端窗口里要已经出现「冥想项目启动成功」，并且那个窗口不能关。

服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

---

## 开始之前要准备什么

安装 **Node.js 20 或更高**（见 `mingxiang-admin/package.json` 的 `engines`，要求类似 `^20.19.0 || >=22.12.0`）：https://nodejs.org/

建议官网下载 LTS 版本。安装时勾选：

- **Add to PATH**（添加到 PATH）

安装完成后，**重新打开终端**（旧窗口认不出新软件），输入：

```bash
node -v
npm -v
```

应看到 `v20.x` 或更高，以及一串 npm 版本号。看不到就说明没装好，或没重新开终端。

浏览器使用 **Chrome** 或 **Edge**。

---

## 第 1 步：确认连的是自己电脑上的服务端

管理端通过一个小配置文件，决定请求发到哪里。

用记事本或 VS Code 打开：

`mingxiang-admin/comment/httpUrl.js`

仓库里可能默认指向线上：

```javascript
const ROOTPATH = "https://mingxiangadmin.xianmaxiong.com/sqx_fast";
```

**在自己电脑上练习时，请改成本机服务端**，保存后再启动：

```javascript
const ROOTPATH = "http://127.0.0.1:9120/sqx_fast";
```

说明：

- 端口必须与服务端一致，默认是 **9120**（不是 8888，8888 是管理端自己的网页端口）。
- 路径必须带 **`/sqx_fast`**，少了会请求失败。
- 改完后如果网站已经在运行，要先在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`，修改才会生效。

部分上传组件里可能写死了线上上传地址（例如 `https://mingxiangadmin.xianmaxiong.com/sqx_fast/alioss/upload`）。本地上传课程封面、音频时，若上传失败，把这些地址也改成本机：`http://127.0.0.1:9120/sqx_fast/alioss/upload`。第一次只想登录看菜单，可以先不改上传地址。

---

## 第 2 步：安装依赖

仓库**不包含** `node_modules`（体积很大，每人电脑自己生成一份）。

1. 打开终端。
2. 进入 `mingxiang-admin` 文件夹。例如：

```bash
cd mingxiang-admin
```

Windows 示例：

```powershell
cd "C:\Users\你的用户名\Desktop\开源-三端\冥想三端开源\mingxiang-admin"
```

3. 执行：

```bash
npm install
```

第一次可能要几分钟到十几分钟。结束时：

- 没有红色 `npm ERR!`
- 这个文件夹里出现了 `node_modules`

就成功了。有红色错误时，先看 `node -v` 是不是 20 以上，再重试。

以后只要没有换电脑、没有改 `package.json`，就不用每次都 `npm install`。

---

## 第 3 步：启动网站

还是在 `mingxiang-admin` 文件夹里执行：

```bash
npm run dev
```

窗口里会出现本地地址。默认端口是 **8888**（见 `vite.config.js`）。没有自动打开浏览器时，自己打开：

http://localhost:8888

登录页上应能看到：

- 标题「省钱兄冥想助眠系统」
- 账号、密码输入框
- 一张验证码图片

看不清就**点图片换一张**。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个终端窗口也要一直开着。关掉后后台网站就打不开了。

---

## 怎样登录、怎样算成功

使用数据库里的管理员（见 [服务端运行教程](服务端-运行教程.md) 第 3 步）：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |
| 验证码 | 登录页图片上的字符（区分大小写，看不清就点图片换一张） |

点「登录」。成功后进入「数据中心」，能看到总用户数、今日新增、收入等数字卡片。

左侧应能看到菜单，例如：

- 数据中心
- 用户中心
- 财务中心
- 消息中心
- 首页装修
- 课程管理
- 订单中心
- 类型配置
- 会员配置、会员特权
- 音乐场景配置
- 帮助中心
- 系统配置
- 系统管理（管理员列表 / 角色管理 / 菜单管理）

开源 SQL 已带菜单与管理员数据。若你自己清空了权限表，侧栏可能变空，需要重新导入 SQL，或在「菜单管理 / 角色管理」中恢复。

课程列表里有演示课程，不代表后台「连错了」——库本来就有演示数据。

要试用支付、短信、微信登录，还需在「系统配置」填写对应密钥。没填时，后台其他菜单仍可点、可改课程。

每个菜单能做什么，见 [管理端功能说明](管理端-功能说明.md)。

## 建议验收路径（给不懂代码的人）

按这个顺序点一遍，确认后台可用：

1. 用 `admin` / `123456` 登录，进入数据中心，数字不是转圈失败。
2. 打开「课程管理」，能看到课程列表；点一条「修改」能弹出表单。
3. 打开「类型配置」，能看到「冥想类型列表 / 标签列表 / 探索分类配置」三个页签。
4. 打开「首页装修」，能看到轮播图，开关可以点。
5. 打开「会员配置」，能看到套餐名称、月数、价格。
6. 打开「系统配置」，能看到微信、支付宝、短信等页签（先看，密钥以后再填）。
7. 打开「系统管理 → 管理员列表」，能看到 `admin` 账号。

改完课程并保存后，再打开用户端首页刷新，应能看到新内容（用户端也要连同一台服务端）。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开终端。

**`npm ERR!` 或引擎版本不符合**  
`node -v` 过低。安装 Node 20+ 后再执行 `npm install`。

**浏览器打不开 localhost:8888**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口（例如 8889），用窗口里打印的那个地址。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `comment/httpUrl.js` 不是你的本机服务端。按键盘 `F12`，点「网络」或 Network，再点一次登录。请求应走到 `127.0.0.1:9120`（或你改过的地址），不应误发到 `mingxiangadmin.xianmaxiong.com`。改完地址后，在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 8888 is in use`**  
8888 已被占用。关掉之前的管理端窗口再启动，或改 `vite.config.js` 里的 `server.port`。

**登录提示验证码不正确**  
图片上的字要和输入完全一致。点图片换一张再试。服务端窗口如果已经关掉，验证码对了也登不进去。

**能登录但左侧几乎没有菜单**  
检查当前账号角色权限，或重新导入 `mingxiang-server/db/mingxiang.sql` 后的菜单 / 角色数据。

**改了系统配置 / 课程信息，用户端没变化**  
确认已经点保存；用户端需要重新打开页面或下拉刷新。服务端窗口必须还在运行。两边必须连同一套服务端。

**本地上传图片 / 音频失败**  
检查上传接口是否仍指向线上域名；改成本机 `http://127.0.0.1:9120/sqx_fast/alioss/upload`，并确认服务端文件目录可写、服务端窗口还在。

**页面空白或控制台报错**  
确认第 2 步 `npm install` 已经成功出现 `node_modules`。删掉后重新 `npm install` 再 `npm run dev`。
